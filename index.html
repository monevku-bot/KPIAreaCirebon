        Langkah sekali saja membuat GitHub Token (100% Gratis):

        1. Buka GitHub → klik foto profil pojok kanan atas → Settings → Developer settings (paling bawah kiri).
        2. Pilih Personal access tokens → Fine-grained tokens → klik Generate new token.
        3. Pada Repository access pilih Only select repositories (pilih repo dashboard Area Cirebon kamu).
        4. Pada Permissions → Repository permissions, ubah Contents menjadi Read and write → klik Generate token lalu tempel di kolom bawah.
        Token hanya disimpan di browser perangkat ini dan tidak ikut terunduh/terpublish.
